# SuperluminalColorMixer

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An advanced, interactive color mixing and visualization web application featuring perceptual color spaces (OKLab), customizable mixing math, and real-time canvas rendering.

## ✨ Features

- **Perceptual Color Mixing**: Accurate color blending powered by OKLab and Color.js.
- **Interactive Visualizers**: OKLab chromaticity visualization, gamut boundary mapping, and real-time color inspect modal.
- **Dynamic Controls**: Fine-tune mixing ratios, canvas dimensions, resolution, and interpolation curves.
- **Modern & Responsive UI**: Sleek dark interface with smooth micro-interactions.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized bundle:

```bash
npm run build
```
